# AGENTS.md — alesle-ai-mobile

Rules for anyone (human or AI) changing this repository. The owner reads and
writes Uzbek; reply in Uzbek. Code, comments, docs and commits are English;
user-facing strings are Uzbek first (ARB), with ru and en.

## Stack

Flutter 3.47.6 / Dart 3.13 · Android only (minSdk 30) · Riverpod 3 · go_router ·
freezed 3 + json_serializable · dio + retrofit generated by swagger_parser ·
Pigeon (Dart ⇄ Kotlin) · Kotlin AccessibilityService · gen-l10n (uz, ru, en).

## Distribution

One build: `com.alesle.ai`, a signed APK from our website only — no Google Play,
no product flavors (ADR 0005 in alesle-ai-api). Do not reintroduce flavors.

`ExecutionPolicy` is a **per-user setting** ("confirm every sensitive action",
on by default; when off, a cancellable countdown). It is never a build property.
Payments, purchases and deletions always require confirmation.

Environments: `--dart-define-from-file=env/{dev,staging,prod}.json`
(`APP_ENV`, `API_BASE_URL` = origin only). `AppConfig.parse` validates them at startup.

## Layout

```
lib/
  app/        bootstrap, router, theme, l10n (ARB + generated)
  core/       config, network (dio, error mapping), errors (Failure),
              api/generated (swagger_parser), platform/generated (Pigeon)
  features/<x>/{domain,data,presentation}
android/app/src/main/kotlin/com/alesle/ai/agent/   native agent runtime
pigeons/      Pigeon contracts (source of truth for the bridge)
openapi/      committed API contract from alesle-ai-api
```

## Non-negotiables

1. **Never weaken a check** — no lowered coverage floors, skipped tests, or
   `// ignore:` without a written reason.
2. **Domain is pure Dart** (no Flutter, dio, Riverpod, generated code).
   `test/arch/layering_guard_test.dart` enforces it.
3. **Generated transport code** (OpenAPI client, Pigeon) is used only in
   `data/` and `core/`. Presentation depends on domain interfaces.
4. **Features never import each other.**
5. **Errors:** repositories throw `Failure` (`NetworkFailure`, `ServerFailure(code)`,
   `UnexpectedFailure`). The UI branches on type and `ErrorCode`, never on text.
6. **Generated files are committed** and must match their sources:
   `tool/check_codegen_drift.sh` (CI runs it). Do not edit them by hand.
7. **API contract changes start in alesle-ai-api**: `yarn openapi:emit &&
   yarn contract:sync` there, then `dart run swagger_parser && dart run
   build_runner build -d` here.
8. **Bridge changes start in `pigeons/`**: `dart run pigeon --input pigeons/agent_api.dart`.
9. **No secrets in the app.** Session tokens live in `flutter_secure_storage`
   only (core/auth); requests get them through `AccessTokenSource`.
10. **No screen content or personal data in logs.**

## Tests

| Layer | Where | Run |
|---|---|---|
| Unit / function | `test/unit/` | `flutter test --exclude-tags golden` |
| Widget | `test/widget/` | (same) |
| Architecture | `test/arch/` | (same) |
| Golden | `test/golden/` | `flutter test --tags golden` (`--update-goldens` after intended UI changes) |
| Kotlin unit (Robolectric) | `android/app/src/test/` | `cd android && ./gradlew testDebugUnitTest` |
| Integration (device) | `integration_test/` | `flutter test integration_test --dart-define-from-file=env/dev.json` |
| E2E (device, crosses into system UI) | `patrol_test/` | `patrol test --dart-define-from-file=env/dev.json` |

Coverage floors (`tool/check_coverage.dart`): overall ≥ 80 %, `lib/core/` ≥ 90 %,
feature `domain/` ≥ 95 %. Generated code is excluded.
